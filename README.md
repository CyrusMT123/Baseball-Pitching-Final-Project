# Baseball-Pitching-Final-Project

The data folder sotres data for the project, which was downloaded as CSVs from Baseball Savant.

The derived folder holds our combined and cleaned data in one csv file.

The visualizations folder holds visualizations we have created, included short form movement plots and larger visualizations showing player similarity and spread of pitch types on an expanded short form movement plot.

The CombiningData.ipynb holds the code that combines the data

The Visualizations.ipynb has code that creates individaul pitcher short form movement plots and simple visualizaitons comparing arm angle and release point metrics.
